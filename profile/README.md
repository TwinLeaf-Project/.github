## 🎯 我們的使命

我們相信，科技應回歸人性——**尊重、美感、易用、自由**。

TwinLeaf Project 是一個源於香港的開源項目，致力於為香港用戶打造尊重私隱、易於使用、美觀自由的數位工具。


核心理念：

| 理念 | 說明 |
|------|------|
| 🤝 **尊重** | 根源切除私隱監控，不收集任何個人資料 |
| 🎨 **美感** | 簡約優雅的介面設計，賞心悅目 |
| ✨ **易用** | 繁體中文開箱即用，降低使用門檻 |
| 🕊️ **自由** | 你就是軟件的主人，而並非普通用戶 |

## 📦 主要項目

| 項目 | 說明 | 狀態 |
|------|------|------|
| [**TwinLeaf OS**](https://github.com/TwinLeaf-Project/TwinLeaf-OS-) | 基於 Ubuntu + 平鋪式UI 的 Linux 發行版 | ⛔ 已停工 |
| **TwinLeaf Browser** | 私隱優先的網頁瀏覽器 | 📋 規劃中 |

---

## 🖥️ 硬體定位

TwinLeaf OS 專為以下設備設計：

| 類型 | 代表機型 | 狀態 |
|------|----------|------|
| **AI PC (2024+)** | Lenovo IdeaPad Slim 3 (R7 8840HS) | ✅ 主力開發平台 |
| **舊筆記本 (2019+)** | Lenovo Yoga (i5-8250U) | ✅ 相容性測試平台 |
| **桌面主機** | 任何 AMD/Intel PC | ✅ 可用 |

## 🌱 關於博藝工作室

TwinLeaf Project 由香港 **博藝工作室（Benmak Workshop）** 創立。靈感來自日本藝人 **守崎風花（nicamoq）** 從普通網民到成熟表演者的轉變，象徵「勇於嘗試」與「溫柔平衡」。
